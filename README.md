# 数学试卷报告

单文件、离线可用的个人试卷诊断网页，包含得分图表、逐题考点、6处失分解析、14天复习打卡和自测题。

- 总分：112 / 150；年级排名：170。
- 根据本人提供的试卷照片、成绩表及错题位置制作。
- 第12–14题单题分值为依据合计分数与错误位置推定，页面已标注。
- 题目难度和复习建议属于教学判断，不是官方统计或评分细则。
- 不包含其他同学姓名、成绩原图或任何认证信息。
- 打卡数据只保存在访问者浏览器中。

## 使用

直接打开 `index.html`，或访问 GitHub Pages。无需安装依赖。可用页面顶部按钮打印或保存PDF。

## 部署

GitHub Pages：仓库已包含 `.github/workflows/pages.yml`，推送到 `main` 会自动构建并发布到 Pages；`.nojekyll` 使页面直接作为静态文件发布。

持续记录工作流：

1. 上传某次小考的成绩截图或文字成绩。
2. 我核对日期、科目、得分/满分、优势考点与薄弱考点；不确定信息会标记待确认。
3. 我把确认后的记录追加到 `data/records.js`，更新页面中的科目趋势、复习优先级和报告说明。
4. 推送到本仓库并更新 Pages。

页面的“添加一次小考”可先在当前浏览器暂存，支持 JSON 导入/导出；本机暂存不会自动写入 GitHub，避免未经审核的成绩污染正式档案。

## 考试难度指标

考试难度使用 0–1 指标：`一本线达标人数 ÷ 参考人数`。数值越接近 1，达到一本线的人数率越高，考试越容易；越接近 0，考试越难。成绩追踪表和新增成绩表单均支持记录一本线人数与参考人数，未提供数据时显示“待补一本线人数”。
